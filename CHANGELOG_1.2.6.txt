Move UI 1.2.6 - LocalClock independent positioning and visibility

- LocalClock registers as a separate Move UI mover.
- LocalClock's offset remains relative to the minimap cluster, so it follows minimap movement while retaining independent placement.
- LocalClock is parented independently so it can be shown without the minimap when explicitly enabled.
- Hiding the minimap suppresses LocalClock by default and hides the native-clock surround through the minimap's own parent visibility.
- The LocalClock Hide checkbox reflects temporary minimap suppression; unchecking it while the minimap is hidden shows LocalClock by itself.
- LocalClock's own Hide preference remains independent and persists when the minimap is shown again.
- Temporary minimap suppression is cleared at startup and recalculated from MinimapCluster visibility.
- Hiding LocalClock affects only the second clock, not the minimap or native-clock surround.
- Preserved the 1.2.5 run timer / boss countdown implementation unchanged.

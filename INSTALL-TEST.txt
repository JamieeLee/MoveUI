MOVE UI 1.2.8 - TOOLS TEST 2

FULL SOURCE ARCHIVE INSTALL
1. Download the branch ZIP from the link in the conversation.
2. Extract it. GitHub names the extracted folder MoveUI-feature-addon-tools-integration.
3. Rename that extracted folder to MoveUI.
4. Copy the MoveUI folder into Azeroth Survivors/Interface/AddOns/.
5. Confirm Interface/AddOns/MoveUI/MoveUI.toc exists directly inside the folder.
6. Start the game and enable Move UI if necessary.

CONTROLS
- /move opens the main Move UI options.
- Left-click the MU minimap bubble to open/close Move UI.
- Right-click the MU minimap bubble to open Add-on Tools.
- Drag the MU bubble around the minimap; the angle is saved.
- /movetools opens Add-on Tools from chat.

INTEGRATED ADD-ONS
- Move UI provides one combined launch point.
- When Move UI is loaded, its own integration hides/disables the BigCursor and LocalClock minimap bubbles.
- BigCursor.lua, LocalClock.lua, their textures, and their standalone ZIP packages are not modified. The bubbles return normally when Move UI is not installed/enabled.
- BigCursor can be enabled/disabled and its settings opened from Add-on Tools.
- LocalClock Options and Clock Tools are available from Add-on Tools.
- LocalClock's actual clock and alarm frames keep their existing Move UI frame-list integration.

This is a test build for in-game verification, not a release.

Move UI 1.2.9 — Unified Add-on Tools and minimap launcher

- Added a classic, draggable Move UI minimap bubble with saved positioning.
- Supports round and square minimap layouts.
- Left-click opens the main Move UI window; right-click opens Add-on Tools.
- Added /movetools as a chat-command shortcut.
- Added BigCursor status, enable/disable, and settings controls.
- Added LocalClock Options and Clock Tools shortcuts.
- While Move UI is loaded, its combined launcher hides and disables the standalone BigCursor and LocalClock minimap bubbles.
- BigCursor and LocalClock source code and standalone packages remain unchanged.
- BigCursor remains a utility and is not added to the movable-frame list.
- Preserved existing Move UI mover behavior, alignment grid, run timer, and LocalClock frame/alarm integration.
- Moved the Add-on Tools button into the title area so it no longer overlaps the Hide column heading.
